

Staging & Committing
git add .                                 # Stage all changes
git add server.js package.json package-lock.json    # Or stage selected files


git commit -m "Update to css code structure before merging to main"

Branching

git checkout -b feature/mailing-feature   # Create & switch to a feature branch
git push origin feature/mailing-feature   # Push feature branch to GitHub
git push heroku feature/mailing-feature:main   # Push your branch to Heroku main

# Merge main into your feature branch (always update before PR)
git checkout main
git pull origin main                     # Get latest changes from main
git checkout feature/mailing-feature
git merge main                           # Merge main into feature branch

Merging Feature & Pushing to Deploy

git checkout main
git merge feature/mailing-feature        # Merge feature into main
git push origin main                     # Push main to GitHub
git push heroku main                     # Deploy to Heroku

git push origin feature/mailing-feature

Removing Secrets From Git History (with BFG)

brew install bfg                         # Install BFG cleaner

# Remove a file from all git history
bfg --delete-files your-secret-keyfile
# Or remove by pattern
bfg --delete-files '*.env'

# After BFG, clean up git and force push:
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force origin main
